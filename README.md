# 🧭 Shturval (Штурвал) — пульт управления магазином Бизмарт

Сайт-пульт для владельца: продажи, товары и финансы из 1С, реклама и учёт проката авто — в одном кабинете.

## Как открыть
Кабинет открывается в браузере, вход по логину и паролю. Ничего устанавливать не нужно.
Данные настоящие и хранятся на сервере — в этом репозитории их нет.

## Что внутри (v6)
- 🏠 **Главная** — все дела на одном экране: сводка словами, магазин сегодня, неделя, месяц, реклама, прокат, склад (видит владелец)
- 📦 **Магазин** — рабочий стол (выручка, график за 30 дней, сравнение с прошлым периодом, «Требует внимания»), товары, продажи, ассортимент, отчёт по продажам, аналитика, поставщики, финансы, расходы
- 📣 **Реклама** — запуск рекламы, отчёты, анализ
- 🚗 **Авто Рент** и **Авто Рент 2** — машины, аренды, расходы, клиенты, календарь, GPS и пробег
- 📋 **Отчёты** — ежедневный отчёт кассиров
- ⚙️ **Настройки** — профиль, логин и пароль, сотрудники и доступы, светлая или тёмная тема

## Как устроено
- `index.html` — кабинет (один файл, без сборки)
- `backend/server.py` — сервер (Python)
- `tools/polygon/` — проверка правок на настоящих данных без записи на сервер, см. `tools/polygon/README.md`
- `tools/checklist/` — проверка кнопок на выдуманных данных
