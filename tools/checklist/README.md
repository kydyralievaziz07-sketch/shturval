# Ежедневный чек-лист: все кнопки кликабельны и работают

Проверка гоняется **на локальном полигоне**, а не на боевом сайте: боевые данные не трогаются,
ничего не удаляется и не сбрасывается.

## Как запустить

```bash
node tools/checklist/mock-server.mjs
```

Полигон поднимется на `http://localhost:8787` — отдаёт корневой `index.html`
(тот же файл, что уходит на Vercel/Pages и на Render для Бизмарта) и подменяет все `/api/*`
фейковыми ответами. Логин и пароль — любые: мок отвечает «владелец, все разделы».
POST-запросы только логируются (`GET /__log` покажет всё, что кнопки пытались отправить).

Дальше в консоли браузера, уже после входа, выполнить содержимое `browser-audit.js` —
он вернёт отчёт объектом.

Плюс две статические проверки прямо по файлу, без браузера:

```bash
node tools/checklist/audit-static.mjs index.html
```

```bash
node tools/checklist/audit-orphans.mjs index.html
```

## Что именно проверяется

| Проверка | Что ловит |
|---|---|
| `audit-static.mjs` | `onclick="foo()"`, где `foo` не объявлена вообще или объявлена не глобально |
| `audit-orphans.mjs` | `<button>` без единого обработчика; `getElementById` по несуществующему id |
| `browser-audit.js`, часть 1 | обход всех вкладок и всех `.modal-bg`: `typeof window[имя]==='function'` |
| `browser-audit.js`, часть 2 | клик по безопасным кнопкам + проверка эффекта (DOM / запрос / модалка) |
| `browser-audit.js`, часть 3 | физическая кликабельность: перекрытие, `pointer-events:none`, нулевой размер |
| `browser-audit.js` | двойная валюта в тексте («сом сом») |

## Безопасность прогона

- `window.confirm` подменяется на «нет» → ни одно подтверждение удаления не проходит.
- Кнопки со словами *удалить, сбросить, очистить, отправить, опубликовать, сохранить, оплатить…*
  не нажимаются вообще, только сверяются их обработчики.
- `alert`/`prompt` заглушены — иначе модальный диалог браузера вешает страницу и обход встаёт.

## Как читать «без эффекта»

Часть кнопок штатно не даёт эффекта на полигоне, это НЕ поломка:

- `📎` и «Загрузить из Excel» — открывают файловый диалог;
- `🎤` — микрофон в автоматическом прогоне недоступен;
- «← Назад» / «Вперёд →» — `disabled`, когда страница одна;
- «Отправить» в пустом поле, «обновить» без выбранного диалога — ранний выход по условию.

## Грабли

- Таймеры в фоновой панели браузера тротлятся: циклы с `await sleep()` застревают на середине.
  Поэтому обход и клики сделаны **синхронными**, а эффект проверяется по длине `innerHTML`
  и счётчику `fetch`, а не через `MutationObserver`.
- Роли проверять отдельно: `USER.sections=['hr']`, `['rent']`, `['dailyrep']`, `[]` —
  часть кнопок рисуется только не-владельцу.
- Демо-аккаунта в кабинете больше нет (`demo/demo2026` удалён), полигон его заменяет.
