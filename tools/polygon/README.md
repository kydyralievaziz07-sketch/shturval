# Полигон «только чтение»

Проверка кабинета на **настоящих данных**, но без риска что-то изменить: локальный сервер отдаёт
`index.html` и пропускает на боевой сервер **только чтение** (GET). Любая запись (POST/PUT/DELETE)
не уходит дальше полигона — она попадает в журнал `/__writes`, а странице возвращается заглушка.
Ответы сервера записываются на диск, поэтому версии «до» и «после» видят одинаковые данные.

Записанные ответы и снимки — это боевые данные магазина. Они лежат во временной папке системы
(`$TMPDIR/shturval-polygon`), **не в репозитории**: репозиторий публичный.

## Запуск

```bash
cd tools/polygon && npm install            # один раз: puppeteer-core (свой Chrome не качает) и acorn
git show HEAD:index.html > /tmp/old.html   # версия «до»
OLD_HTML=/tmp/old.html node ro-proxy.mjs   # полигон на http://localhost:8787 (old.html и new.html)
```

В другом окне:

```bash
node walk.mjs /old.html out-old            # обойти все вкладки старой версии, запомнить текст
node walk.mjs /new.html out-new --shots    # то же для рабочего index.html (+ снимки экрана)
python3 cmp.py $TMPDIR/shturval-polygon/out-old $TMPDIR/shturval-polygon/out-new
curl -s localhost:8787/__writes            # что страница пыталась записать (должно быть [])
```

`walk.mjs` входит под владельцем (логин и пароль берёт из `backend/secret.env`), открывает каждую
вкладку в безголовом Chrome с отдельным временным профилем и ловит ошибки JavaScript.
Флаги: `--mobile` (экран телефона), `--shots`, `--tabs=shop:dash,rent:rentlist`.

`cmp.py` сравнивает текст вкладок без учёта регистра. Вкладка «совпала» = на ней те же цифры и
строки, что были до правки. Это и есть проверка «данные не изменились».

## Остальное

- `probe.mjs /new.html shop dash "<выражение JS>" --shot=/tmp/x.png` — открыть вкладку, вычислить
  выражение, снять экран. Так же запускается `../checklist/browser-audit.js` (клики по кнопкам):
  `node probe.mjs /new.html shop dash "(window.toggleDrawer=function(){}, $(sed 1,5d ../checklist/browser-audit.js))"`.
- `REPLAY_ONLY=1 node ro-proxy.mjs` — вообще не ходить на боевой сервер, отвечать только из записи.
  Нужен для прогона кликов по кнопкам: кнопки дёргают много разных запросов.
- `NO_CACHE=1 node ro-proxy.mjs` — «примерочная» для владельца: открыть `http://localhost:8787/new.html`,
  войти своим логином и смотреть новую версию на свежих данных. Сохранения при этом не срабатывают.
- `dce.mjs report index.html` — какие функции и переменные никем не используются;
  `dce.mjs apply index.html out.html` — вырезать их. Перед `apply` всегда обход и сравнение.

## Грабли

- Цифры на карточках «набегают» 0,75 с. Обход ждёт 1,2 с после загрузки, иначе поймает середину.
- Кнопка «Показать все» на рабочем столе открывает шторку уведомлений, и она перекрывает всё
  остальное — в прогоне кликов шторку надо заглушить (`window.toggleDrawer=function(){}`).
- На перегруженном Маке Chrome стартует дольше 30 секунд — таймаут запуска поднят до 3 минут.
- Порт 8787 общий с `../checklist/mock-server.mjs`: одновременно работает что-то одно.
